# CinePass – Ticket Booking System

CinePass is a full-stack ticket booking system that allows users to view shows, select seats, and manage ticket bookings through an interactive interface.

## Features

- Interactive cinema seating layout
- Seat selection and booking
- Real-time seat availability updates
- User switching for testing multiple users
- Booking status tracking
- Show and movie information
- Live synchronization of seat updates
- Responsive web interface

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data MongoDB
- Maven

### Frontend
- HTML
- CSS
- JavaScript

### Database
- MongoDB
